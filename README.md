## 1. Резюме (Executive Summary)

В ходе лабораторной работы был спроектирован процесс разработки для микросервиса «Расчет корзины и скидок». Выполнен сравнительный анализ СУБД, настроена инфраструктура репозитория на GitHub, внедрен CI/CD с линтером flake8, проанализирован legacy-код и составлен план code review.

## 2. Сравнительный анализ технологий

### 2.1. Матрица принятия решений

| Критерий выбора | Вес | PostgreSQL (1-5) | MongoDB (1-5) | Взвешенная оценка PostgreSQL | Взвешенная оценка MongoDB |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Поддержка ACID-транзакций | 0.50 | 5 | 3 | 2.50 | 1.50 |
| Производительность чтения | 0.20 | 4 | 5 | 0.80 | 1.00 |
| Гибкость схемы данных | 0.15 | 3 | 5 | 0.45 | 0.75 |
| Зрелость экосистемы | 0.15 | 5 | 4 | 0.75 | 0.60 |
| **ИТОГО** | **1.00** | | | **4.50** | **3.85** |

### 2.2. Расчет и обоснование выбора

Формула: `Оценка = Сумма (Вес_критерия * Балл_кандидата)`

- **PostgreSQL**: 0.50×5 + 0.20×4 + 0.15×3 + 0.15×5 = **4.50**
- **MongoDB**: 0.50×3 + 0.20×5 + 0.15×5 + 0.15×4 = **3.85**

**Победитель: PostgreSQL** — выбор обоснован критической важностью ACID-транзакций для финансовых данных.
