# План Code Review для модуля `src/discount.py`

## 1. Цели ревью
- Обеспечить точность математических расчетов стоимости корзины.
- Гарантировать защиту от фрода (мошенничества) при применении промокодов.
- Проверить корректность и предсказуемость применения скидок.

## 2. Измеримые критерии качества
- **Отсутствие магических чисел**: все коэффициенты (0.85, 0.97, 0.70 и т.д.) должны быть вынесены в константы или конфигурационный файл.
- **Валидация входных данных**: функция должна корректно обрабатывать отрицательные значения `cart_sum`, пустые списки `promos` и невалидные `tier`.
- **Покрытие тестами**: модуль должен иметь unit-тесты с покрытием (coverage) не менее 80%, включая граничные условия (например, скидка ровно 30%).

## 4. Механизм эскалации при спорах
Если между автором и ревьюером возникает спор по поводу архитектурного решения или логики расчета:
1. Обсуждение переносится в голосовой чат или на короткую встречу (15 мин).
